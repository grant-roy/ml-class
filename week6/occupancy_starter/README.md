## Classification of Occupancy Data

We have data from various sensors designed to detect whether or not a room is occupied.

The data is separated into training and testing sets.

Our goal will be to run the pocket algorithm on the dataset, using different values for N.

When N=100 we will use 100 samples from *datatraining.txt* to train the pocket algorithm. For each N, we
will also calculate the generalization bound, given in the Ipython Notebook.

Essentially our task will be to construct the necessary functions to make the notebook functional.
